# matheuscabral.dev

Modern personal website for a data engineer, built with Astro 5 (SSG), TypeScript, and vanilla CSS with CSS custom properties.

## Quick start

```bash
npm install
npm run dev
```

Open `http://localhost:4321`.

## Common commands

```bash
npm run dev          # local dev server (hot reload)
npm run build        # production build
npm run preview      # preview the built site
npm run lint         # Astro type check
npm run format       # format files
npm run test         # Playwright tests
```

Tip: For local builds you can disable Astro telemetry:

```bash
ASTRO_TELEMETRY_DISABLED=1 npm run build
```

## Project structure

```
src/
├── components/       # Reusable Astro components (Card, Button, Icon, Timeline, …)
├── content/          # Markdown content collections
│   ├── blog/         # Blog posts
│   └── projects/     # Portfolio projects
├── data/
│   └── site.ts       # All site-wide copy, nav links, timeline, skills, etc.
├── layouts/
│   └── BaseLayout.astro
├── pages/            # File-based routing (index, about, blog, portfolio, resume, contact, 404, rss.xml)
├── scripts/          # Client-side TypeScript modules
│   ├── theme.ts          # Dark/light theme toggle (no FOUC)
│   ├── mobile-menu.ts    # Mobile nav with keyboard/focus support
│   ├── scroll-reveal.ts  # IntersectionObserver reveal animations
│   └── card-equalizer.ts # Card row height equalisation
└── styles/
    ├── global.css        # Entry point — imports the six modules below
    ├── tokens.css        # CSS custom properties (colours, spacing, type scale, …)
    ├── base.css          # Reset, body, global element styles
    ├── layout.css        # Grid helpers, hero, post layout, section utilities
    ├── components.css    # Cards, buttons, nav, TOC, timeline, footer, …
    ├── pages.css         # Page-specific styles (about, contact, resume, …)
    └── utilities.css     # Scroll-reveal, print, reduced-motion overrides
```

## Content and copy updates

### Site metadata and hero content

Edit `src/data/site.ts` for:

- name, location, email, availability
- highlights, metrics, values
- `skills` — array of `{ title, icon, items[] }` objects (icons reference `src/components/Icon.astro`)
- timeline, spokenLanguages, interests
- featuredHighlights (hero panel)

### Add a project

1. Create a Markdown file in `src/content/projects/`.
2. Use the frontmatter schema from the examples:
   - `title`, `description`, `tags`, `stack`, `highlights`, `links`, `featured`, `status`
3. Projects appear on `/portfolio`, and featured ones appear on the home page.

### Add a blog post

1. Create a Markdown file in `src/content/blog/`.
2. Include `title`, `summary`, `date`, and `tags` in frontmatter.
3. Posts appear on `/blog` and the latest show on the home page.
4. Headings (`##`, `###`) are automatically surfaced in the sticky TOC sidebar on the post page.

### Adding new icons

Icons live in `src/components/Icon.astro` as inline SVG cases. To add a new icon:

1. Add a new `name === 'your-icon-name'` block inside the `<svg>` element.
2. Use Heroicons 2.0 outline paths (`fill="none"`, `stroke="currentColor"`, `stroke-width="1.6"`).
3. Reference it with `<Icon name="your-icon-name" size={16} />`.

## Contact form (Netlify Forms)

The contact form is wired for Netlify Forms in `src/pages/contact.astro` and posts to `/success`.

- Submissions are handled only on the deployed Netlify site.
- Local dev does not send form submissions.

## Deployment (Netlify)

`netlify.toml` is configured for Astro:

- build command: `npm run build`
- publish directory: `dist`
- Node version: `22`

Make sure your Netlify UI settings match (base directory should be empty or `.`).

## SEO and social previews

- Default OG image: `public/og-default.png`
- Favicon: `public/favicon.svg`
- Sitemap: generated by `@astrojs/sitemap`
- RSS feed: available at `/rss.xml` (generated by `@astrojs/rss`)
- Structured data: JSON-LD Person schema injected in `BaseLayout.astro`

## Testing (Playwright)

```bash
npx playwright install
npm run test
```

Playwright uses the built site via `npm run build` + `npm run preview`.

## Tooling notes

- Project-local installs (npm): Astro, @astrojs/sitemap, @astrojs/rss, @astrojs/check, Playwright, Prettier, and font packages.
- Global installs (Homebrew): Node.js + npm, Google Chrome (for Playwright MCP validation).
- Conda: not used for this project.
